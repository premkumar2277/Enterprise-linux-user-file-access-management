
# Linux Commands Reference

This document lists the Linux commands used while building the **Enterprise Linux User, File & Access Management System** project.

---

# 1. Navigation Commands

| Command | Description |
|----------|-------------|
| `pwd` | Display current working directory |
| `cd` | Change directory |
| `ls` | List directory contents |
| `ls -l` | Long listing format |
| `ls -a` | Show hidden files |
| `ls -R` | List directories recursively |
| `tree` | Display directory structure |

---

# 2. Directory Management

| Command | Description |
|----------|-------------|
| `mkdir` | Create directory |
| `mkdir -p` | Create nested directories |
| `rmdir` | Remove empty directory |

---

# 3. File Management

| Command | Description |
|----------|-------------|
| `touch` | Create an empty file |
| `cp` | Copy files/directories |
| `cp -r` | Copy directories recursively |
| `mv` | Move or rename files |
| `rm` | Remove files |
| `rm -r` | Remove directories recursively |
| `cat` | Display file contents |
| `less` | View file page by page |
| `head` | Show first lines of a file |
| `tail` | Show last lines of a file |

---

# 4. User Management

| Command | Description |
|----------|-------------|
| `useradd` | Create a user |
| `passwd` | Set or change a user's password |
| `usermod` | Modify user account |
| `userdel` | Delete a user |
| `id` | Display user and group information |
| `whoami` | Show current user |

---

# 5. Group Management

| Command | Description |
|----------|-------------|
| `groupadd` | Create a group |
| `groupdel` | Delete a group |
| `gpasswd` | Manage group memberships |

---

# 6. Permission Management

| Command | Description |
|----------|-------------|
| `chmod` | Change file permissions |
| `chown` | Change file owner |
| `chgrp` | Change file group |
| `umask` | Set default permissions |

---

# 7. Search Commands

| Command | Description |
|----------|-------------|
| `find` | Search files and directories |
| `grep` | Search text in files |
| `locate` | Locate files by name |

---

# 8. Archive & Backup

| Command | Description |
|----------|-------------|
| `tar` | Archive files |
| `gzip` | Compress files |
| `gunzip` | Decompress files |

---

# 9. Disk Usage

| Command | Description |
|----------|-------------|
| `df -h` | Show filesystem usage |
| `du -sh` | Show directory size |

---

# 10. System Information

| Command | Description |
|----------|-------------|
| `hostname` | Display system hostname |
| `uname -a` | Show kernel information |
| `date` | Display current date and time |
| `uptime` | Show system uptime |

---
