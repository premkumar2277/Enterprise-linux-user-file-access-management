
# Learning Outcomes

## Overview

This project provided hands-on experience with Linux system administration by simulating a real enterprise environment using **Red Hat Enterprise Linux 9 (RHEL 9)**.

It strengthened my understanding of Linux fundamentals and prepared me for DevOps, Cloud, and Multi-Cloud engineering roles.

---

# Linux Fundamentals

After completing this project, I gained practical knowledge of:

- Linux File System Hierarchy (FHS)
- File and Directory Management
- Linux Command-Line Interface (CLI)
- Absolute and Relative Paths
- File Creation and Management

---

# User Administration

I learned how to:

- Create users using `useradd`
- Set passwords using `passwd`
- View user information using `id`
- Switch users using `su`
- Verify user accounts using `/etc/passwd`

---

# Group Administration

I learned how to:

- Create groups using `groupadd`
- Add users to groups using `usermod`
- Verify groups using `/etc/group`
- Manage shared access through Linux groups

---

# File Ownership

I gained experience with:

- Changing ownership using `chown`
- Changing group ownership using `chgrp`
- Understanding owner, group, and others

---

# Linux Permissions

I learned:

- Read, Write, Execute permissions
- Numeric permissions (770, 775)
- Permission verification using `ls -l`
- Secure directory access

---

# SGID (Set Group ID)

I implemented SGID to:

- Allow collaborative file sharing
- Ensure new files inherit the correct group
- Simulate enterprise team collaboration

---

# Enterprise Directory Design

I created a structured Linux environment containing:

- Department directories
- Shared directory
- Reports
- Logs
- Backups
- Scripts

This simulated a real organization's Linux server.
