
# Enterprise Linux User, File & Access Management System

## Overview

This project demonstrates the implementation of a secure enterprise Linux environment using **Red Hat Enterprise Linux 9 (RHEL 9)**.

The project simulates a real organization's file system by creating department-specific directories, users, groups, permissions, and shared collaboration areas.

It focuses on Linux administration fundamentals that are commonly used by Linux System Administrators, DevOps Engineers, and Cloud Engineers.

---

## Business Scenario

A company has five departments:

- Human Resources
- Engineering
- Finance
- Sales
- IT Support

Each department requires:

- Its own secure directory
- Dedicated users
- Department-specific group
- Controlled file access

The company also requires a shared directory where multiple departments can collaborate securely.

---

## Project Objectives

- Design an enterprise directory structure
- Create Linux users and groups
- Configure ownership and permissions
- Implement SGID for collaborative directories
- Test user access control
- Follow Linux administration best practices
